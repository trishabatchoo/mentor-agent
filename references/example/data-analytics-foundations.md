## Project 2 — Assess a Data Project’s Feasibility

### Scenario

A fictional community transportation organization wants to determine
whether its available data can support decisions about expanding a
bike-share program.

### Deliverables

- Requirements brief
- Six source datasets
- Data relationship diagram
- Analysis notebook
- Feasibility memo

### Milestones

| Milestone | Evidence | Progress |
|---|---|---|
| Collect the source data | Six datasets identified | 20% |
| Load and inspect the data | Six DataFrames with inspection notes | 40% |
| Connect the datasets | Shared keys documented and joins tested | 60% |
| Assess data quality | Missing values and limitations documented | 80% |
| Complete the feasibility memo | Final recommendation about data suitability | 100% |

### Evaluation criteria

- Required datasets are identified and documented
- Data is loaded successfully
- Relationships between datasets are explained
- Data-quality limitations are supported by evidence
- Conclusions distinguish feasibility from a final business recommendation

### Common blockers

- Confusing source documentation with downloaded data files
- File paths failing in a hosted notebook
- Unclear join keys between datasets
- Drawing conclusions before validating data quality
